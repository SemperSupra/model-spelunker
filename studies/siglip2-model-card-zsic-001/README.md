# Rep 1 — SigLIP2 model-card reproduction

This study is an overt-public **computational reproduction** of the documented zero-shot image-classification usage example for `google/siglip2-base-patch16-224`.

It is intentionally not presented as reproduction of the SigLIP2 paper benchmark tables.

## Execution ownership

- Model Spelunker owns the study declaration, public-safe runner, and scientific result semantics.
- Model Artifact Foundry supplies the exact model identity and per-file hashes.
- Agent Dispatch supplies the generic sealed public-execution lane.
- The project-owned `workset.json` grants only one bounded sealed public assignment for this rep.

Do not add a Model Spelunker-specific scheduler or GitHub Actions compute hub for this study.

## Evidence semantics

Execution and scientific dispositions are separate. A successful GitHub Actions run can still produce a scientific `NOT_SUPPORTED` result, and a runtime failure is not evidence against the scientific claim.
