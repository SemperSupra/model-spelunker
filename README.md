# model-spelunker

Experimental infrastructure for observing, falsifying, and causally testing how concepts are represented and transformed inside language models.

## Research lanes

- [Multilingual Concept Geometry & Training Dynamics](docs/research/multilingual-concept-geometry.md)
- [Experiment 0001 — Behavioral Multilingual Concept Geometry](experiments/0001-behavioral-multilingual-concept-geometry.md)

The first execution path is deliberately CPU-only and behavioral. Internal representation mapping, causal interventions, checkpoint dynamics, and training-data attribution are promotion stages for signals that survive cheap controls.
