# model-spelunker

Experimental infrastructure for observing, falsifying, and causally testing how concepts are represented and transformed inside language models.

## Research lanes

- [Neuralese Interface Discovery & Latent Reasoning](docs/research/neuralese-interface-and-latent-reasoning.md)
- [Multilingual Concept Geometry & Training Dynamics](docs/research/multilingual-concept-geometry.md)
- [Experiment 0001 — Behavioral Multilingual Concept Geometry](experiments/0001-behavioral-multilingual-concept-geometry.md)
- [Experiment 0002 — External-to-Latent Interface Discovery](experiments/0002-external-to-latent-interface-discovery.md)
- [Experiment 0003 — Latent Reasoning Trajectories / Neuralese CoT](experiments/0003-latent-reasoning-trajectories.md)

Experiment 0001 is a cheap probe-quality and confound-control feeder. The primary Neuralese objective begins with Experiment 0002: discover an external-to-latent map that is readable, causally writable, transferable, and reusable. Experiment 0003 studies the related but distinct problem of latent reasoning trajectories and continuous/soft chain-of-thought mechanisms.
