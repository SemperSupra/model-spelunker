# R15 — Existing nginx authenticated class reservation, paired baseline

Authority: Model Spelunker #316 and this parent [mTLS PR #356](https://github.com/SemperSupra/model-spelunker/pull/356). Continue using the **same R13 runner**, pinned Ollama 0.34.1, Qwen3:1.7b, disposable synthetic CA/certificates and existing nginx apt package, with no new scheduler or service. R13 per-cert/global quota evidence is archived separately; this R15 extension is a *new* exact-head workload and cannot rewrite its receipt.

Two nginx loopback HTTPS virtual servers share **one model backend** and trusted CA:
- Baseline 18444: mTLS required, explicit allowlist of Alpha (interactive) and Beta (batch) verified client certificate subject, global max connections 2, no class reservation.
- Candidate 18445: same mTLS and global max connections 2, with additional batch class limit 1. The nginx `map` derives class from **verified client-cert subject and `ssl_client_verify`**, not an `X-Class` or `X-Tenant` header. Alpha is explicitly interactive; Beta is batch; valid but unmapped Gamma must be rejected 403. No-client and rogue CA must be denied. Each batch client deliberately spoofs `X-Class:interactive` in the synthetic request; role/quota still depends on cert.
- Start two long batch requests 150ms before one short interactive, compare number admitted (HTTP200) versus rejected (HTTP503), interactive first-token delay if admitted, and full completion wall. Only 2 observations per policy class, this is **admission screening**, not a probability distribution or latency SLO.

**Falsifiable outcomes:** baseline both batch requests can use all 2 global slots and later interactive gets 503; candidate only 1 batch consumes capacity, interactive should receive 200 (with streamed completion), another batch gets 503. Both trials must use equal per-class prompt/response budgets and fully synchronized earlier batch offers, with interactive arriving after both batch requests started but before any batch completed. No retry. Fail closed on unexpected status, invalid request counts, identity mismatch, wrong certificate acceptance or missing model completion. Record results+config hash without certificate keys.

**Important remaining gaps:** Trusted **certificate-to-role authority is not provided** by using synthetic CN allowlists in a lab. CA issuance, revocation, certificate-role mapping, role eligibility and audit belong in owning IaC/gateway DLE. Two HTTPS ports are experimental and do NOT prove that an attacker cannot reach the interactive listener with another authorized cert, nor that traffic cannot bypass both. Hard GPU preemption, sustained class fairness, probabilistic tail SLO and distributed quotas remain UNKNOWN. These are existing nginx budgeting primitives, not full scheduling. No production traffic or private GHA minutes.
