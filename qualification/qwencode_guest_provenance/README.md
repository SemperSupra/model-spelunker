# Qwen Code guest-input reuse — public source-only band B06

This band does **not** create or boot a VM. It prevents wasteful rediscovery of guest sources and overclaiming old results. The public [Agent Dispatch H0 VM lifecycle](https://github.com/SemperSupra/agent-dispatch/actions/runs/36688159026), [Windows Evaluation boot with independent gate](https://github.com/SemperSupra/agent-dispatch/actions/runs/44558554583), and [first logon / PowerShell Direct](https://github.com/SemperSupra/agent-dispatch/actions/runs/44608439342) have different proof limits. The latter original run completed with a **failed independent gate due to receipt filename**, and its [read-only recovery verifier](https://github.com/SemperSupra/agent-dispatch/actions/runs/44613887489) succeeded. The public [Qwen-specific H0](https://github.com/SemperSupra/model-spelunker/actions/runs/44874310455) is separately proven.

The registry `public-sources.json` pins source commits, exact run IDs, the public Microsoft Windows Enterprise Evaluation ISO SHA256 and wimlib SHA256 inherited from the source, and the corrected evidence classifications. `reduce.py` is pure standard-library read/validate/classify logic; it cannot authenticate GitHub signatures or dispatch work. The real-time source/CI check is a supervisor duty before acceptance. Red-team tests forbid transforming `H0` into guest OS boot, or transforming reusable WinBot guest proof into a **Qwen installed in guest** claim. The source deliberately records Qwen installation, Qwen tool use, inference, MCP, and sovereign host admission as **NOT_TESTED / BLOCKED_ADMISSION**.

For eventual Qwen guest H2, consume the already pinned [Windows standalone Qwen Code v0.28.3 release](https://github.com/SemperSupra/model-spelunker/pull/221) only through the existing authorized Agent Dispatch fixed guest/PowerShell Direct builder and an exact separately admitted public-safe assignment. Do not reproduce the 8+GB Windows media on every diagnostic rep, create another hypervisor controller, assume a parent workflow grants private code admission, check out private infrastructure on public Actions, or make a persistent local host change.

References: [batch issue #224](https://github.com/SemperSupra/model-spelunker/issues/224), [public Qwen #220](https://github.com/SemperSupra/model-spelunker/issues/220), [private IaC #601](https://github.com/mark-e-deyoung/infrastructure-as-code-private/issues/601), [Agent Dispatch #406](https://github.com/SemperSupra/agent-dispatch-private/issues/406). This is an **independent lightweight source/provenance critic**, not the heavy H1/H2 execution job.
