# Real public Qwen3 model × synthetic context-size crossover (B08)

Authoritative Model Spelunker [#206](https://github.com/SemperSupra/model-spelunker/issues/206), parallel-batch [#224](https://github.com/SemperSupra/model-spelunker/issues/224).

The real native Qwen Code v0.28.3→Ollama Qwen3:1.7b instrumented job [44876312124](https://github.com/SemperSupra/model-spelunker/actions/runs/44876312124) **FAILED** with `Model stream ended with empty response text`, after 5 serial retry envelopes, **29,365 bytes** each, **14,459 system-content characters**, **3 advertised tools**, first SSE event **72.563 seconds**, subsequent retries ~0.3 seconds, **0 tool deltas**. This is a bounded actor/task-class negative. By contrast [direct real-model job 44875976976](https://github.com/SemperSupra/model-spelunker/actions/runs/44875976976) **PASSED** a small tool schema in both streamed and nonstreamed OpenAI-compatible responses.

This independent experiment reuses the **exact preceding public PR #230 pinned Ollama 0.34.1 and Qwen3:1.7b model**, with two independent disposable standard public Ubuntu 24.04 hosted jobs. Each does a single streaming direct `/v1/chat/completions` call to runner-local Ollama, with `reasoning_effort:none` and identical model, user question, temperature and output budget. The independent variable is *prompt/tool context envelope*: small fixture has a short system message plus one tool; large uses a purely fabricated 14,459-character system message, three public synthetic tools and ~29,365 input bytes. Fake instructions are benign and are **not copies of the Qwen source/system prompt**.

Independent offline job checks exact source structure and no secrets/private model routes. The two actual model jobs execute in parallel up to GHA max-parallel 2, emit isolated timing, finish reason, response tool-call validity and success/failure receipts, with no raw prompt/model text or credentials retained. `PASS` means real local model emits a valid `read_file(file_path="fixture.txt")` call, **not** that the tool executes or Qwen Code runs. `FAIL` shows the model task envelope cannot be accepted under this exact small CPU model and bound. This tests a hypothesis; a large prompt failure may not be the sole root cause of the full agent failure.

No private source, user instruction text, BigMac/TrueNAS API access, real shell effects, host installation, privileged admission, persistent model runtime, paid/private runner, or production release. All original full Qwen harness and workcell holds remain. Parent [public Qwen capsule PR #221](https://github.com/SemperSupra/model-spelunker/pull/221) and reusable [direct model PR #230](https://github.com/SemperSupra/model-spelunker/pull/230) remain separate draft integration surfaces.
