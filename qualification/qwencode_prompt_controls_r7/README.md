## Source facts, exact pinned upstream

Verified official release tag: `QwenLM/qwen-code@v0.28.3` commit `99fcf89892f1a3a8027c75468546c7e7be906245`. `source-pins.json` records exact four source *Git blob* hashes; the public CI independent critic checks these against the real public source checkout and mutated negative fixtures, not just documentation.

- `packages/core/src/core/prompts.ts`: `QWEN_SYSTEM_MD` pointing at a real file **replaces the default base system prompt**, although `assembleSystemPrompt` can still append context files/appendPrompt; an empty file can suppress the base guidance. This is an **explicit and powerful trust control**, not a harmless style knob. A short test-only system prompt must explicitly restate restrictions. `QWEN_SYSTEM_IDENTITY_MD` changes only identity and **does not** eliminate the large base prompt. `QWEN_WRITE_SYSTEM_MD` can write the prompt; set it to `0` in test.
- `packages/cli/src/config/config.ts`, `packages/core/src/config/config.ts`: `--core-tools read_file`/`tools.core` is a tool registration allowlist. The currently supported `tools.eager` defers schema exposure; it is **not a permission or denial mechanism**. `visible` and `allowedTools` are distinct surfaces and cannot be treated as an effect grant.
- A real native Qwen Code + Ollama/Qwen3:1.7b full prompt run [44876312124](https://github.com/SemperSupra/model-spelunker/actions/runs/44876312124) failed after ~29,365-byte prompt envelopes and no valid streamed tool calls. A synthetic direct 29KB model request [44876698668](https://github.com/SemperSupra/model-spelunker/actions/runs/44876698668) timed out at 120s, whereas 8.9KB/three-tool [44877989129](https://github.com/SemperSupra/model-spelunker/actions/runs/44877989129) completed. The bounded next experiment must use the **real native CLI** and a truly smaller system instruction, not infer end-to-end success from direct model tool selection.

## Independent public experiments

Two free public Ubuntu 24.04 GHA jobs run in parallel, `fail-fast:false`: (A) full source-frozen prompt/tool-control audit and negative mutants, (B) **actual Qwen CLI** + digest-pinned real CPU local Ollama/Qwen3:1.7b with a random file fixture and a runner-owned short `QWEN_SYSTEM_MD`, a read_file-only tool allowlist and headless bounded session. A separate localhost-only metadata proxy records **request bytes, system-content chars, tool count, first streamed event, tool deltas, time**, but no raw prompt, tool args, fixture nonce, credentials, host identity or model text. Strict acceptance for B: CLI exits success, final output contains the hidden fixture value, a streamed tool-call delta is observed and every upstream request is less than 14KB/5,000 system chars/at most four advertised tools.
