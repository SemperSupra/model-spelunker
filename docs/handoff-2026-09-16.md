## Operating doctrine

Use these as constraints, not suggestions:

- Evidence over architecture. Every primitive must earn retention empirically.
- Adopt before build. Inspect existing model/library/repo interfaces before adding bespoke machinery.
- Preserve planned-vs-executed methodology, provenance, failures, and deviations; add governance only when it materially improves reproducibility, interpretation, falsification, or evidence preservation.
- Prefer one bounded public/free GitHub Actions model lane at a time. Pack useful work into one hydrated/model-loaded runner before considering parallelism.
- Correctness must not depend on concurrency or cache hits.
- Foundry immutable artifact identity is scientific identity. Actions cache is only an evictable acceleration layer and must never replace Foundry/content verification.
- Reduce tensors/statistics at the runner edge. Do not persist raw activation corpora when compact geometry/hashes answer the question.
- Keep independent validation separate from scientific outcome. Validators check identity, completeness, finite/consistent measurements, schema, and declared invariants; they must not reject surprising scientific results.
- Use holdouts/frozen candidates before promotion. Kill attractive weak effects when replication fails rather than rationalizing them.
- Keep public shared-resource use conservative: low concurrency, cancel superseded work, back off under pressure, no quota-maximizing behavior.
- Do not add another scheduler, registry, state machine, or authority layer unless observed failure earns it.

Primary execution invariant: **exploit locality and reuse before exploiting concurrency.**

## What has earned retention

### Common research/evidence pattern

The portable core is now:

`exact artifact identity -> deterministic/frozen probe -> observe -> contrast -> derive compact geometry/metrics -> independently validate -> retain bounded evidence -> replicate/falsify before promotion`

ObservationBundle-style evidence, exact code/model/runtime provenance, bounded artifacts, explicit uncertainty/assumptions, and independent validators have survived multiple model classes.

### Execution mechanics

- Shared-runtime/model batching has repeatedly matched fresh-process execution with zero observed deltas in checked deterministic metrics; keep it.
- Runner-local reuse and one-load-many-probes are default when scientifically compatible.
- Exact prebuilt runtime caching has earned retention. One qualification measured roughly 39.18 s cold vs 5.50 s warm to validated-ready state (~7.1x setup reduction), with identical dependency/smoke hashes.
- Cache miss remains a normal, correct path.
- Cache availability can differ by branch/ref; never assume a sibling branch will hit.
- Reduce evidence on-runner and upload one compact batch artifact where practical.

## Important falsifications / traps — do not repeat blindly

1. **A/B forced-choice scoring was heavily boundary/token-prior confounded.** Binary “correct beats one distractor” results overstated capability. Use broader candidate neighborhoods/ranks or task-appropriate surfaces.
2. **Candidate likelihood and greedy generation can disagree.** Preserve both as separate diagnostics.
3. **User-start/chat wrapper effects were not a general capability recipe.** They changed state/policy in task-dependent ways.
4. **No universal additive start-token steering vector was recovered.** Residual-direction POKE and small local direct patches failed to reproduce the external token effect reliably.
5. **Attention sink behavior is not a bespoke special-token opcode.** Ordinary prefixes/newlines can engage it; use established attention-sink framing.
6. **Frozen sink-token `A` candidate failed preregistered replication.** Do not reopen a vocabulary sweep to rescue it without a new hypothesis.
7. **One utterance per language/speaker is insufficient for population-style audio robustness inference.** Rep 31/32 showed material speaker and within-speaker utterance/content variance.
8. **Robustness is not generally a stable speaker-only coefficient.** German/French in the selected MLS panel showed strong between-speaker components; Spanish often showed within-speaker utterance/content variance dominating.
9. **Naive temporal alignment can misread pure time shifts.** Feature-level leading silence aligns essentially perfectly after known offset; the Whisper encoder still breaks shift equivariance.
10. **FLEURS Dataset Viewer / first-rows acquisition path failed and was removed.** Current audio branch head deliberately deletes that dead lane. Do not re-add it unchanged.
11. **A red workflow badge can be bookkeeping rather than science failure.** Chronos TS-IMPULSE-1 had a validated scientific run and later green rerun after stale summary metric names were repaired. Distinguish science/validator status from summary/upload plumbing.

## Early causal-LM science checkpoints worth remembering

SmolLM2 exact early model revision used in executable MVP: `e2c3f7557efbdec707ae3a336371d169783f1da1`; exploratory content-manifest identity `sha256:73767c5ee017369d6289f01c15a545fe33d2b23354ac4191b0e6f89089ba9b48`.

Key lessons:

- Serialization/protocol can produce huge internal state changes and apparent policy changes; always test protocol dependence before attributing behavior to the model.
- Removing answer-boundary confounds shrank some giant apparent system-wrapper effects dramatically.
- Candidate-neighborhood ranking is substantially safer than binary A/B tests.
- User-start marker altered attention routing/task behavior, but useful/harmful effects were task-specific.
- Residual steering and small state-patching falsifiers prevented overclaiming a universal control vector.
- Attention localization revealed strong early-prefix sink routing, but ordinary prefix tokens/newline could trigger it.
- Frozen sink-token candidate `A` failed larger replication and was killed.

Cross-family portability then passed on Qwen2.5-0.5B and TinyLlama 1.1B, graduating the common causal-LM instrument set.
